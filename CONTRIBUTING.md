# Contributing

Corrections, questions, and proposed improvements are welcome through GitHub issues and pull requests.

## Scope

Contributions may address the examination method, conversational guidance, record format, template, documentation, or fictional examples. Do not contribute real specimen data, sensitive locality information, personal information, confidential material, or third-party content without permission.

## Changes to `AGENTS.md`

The section between the `eco.records:specimen-identification` marker comments is synchronised from a canonical copy maintained in `eco.records`. That package is currently a private development package and is not presented as a CRAN-ready release. Access may be made available on request where it would help with a proposed contribution, but contributors do not need the package in order to suggest improvements here. Please do not remove the markers.

Proposals for that managed section are welcome through this public repository. Describe the reason for the change and, where possible, provide a concrete example of the problem it addresses. The maintainer will incorporate accepted changes into the private canonical source and then synchronise this repository so the public copy does not drift.

Repository-specific instructions outside the markers may be edited directly.

## Pull requests

- Keep each pull request focused on one coherent change.
- Distinguish observed limitations from expected or hypothetical behaviour.
- Use fictional or generalised information in examples.
- Preserve stable headings, identifiers, and field labels in the record format unless the change deliberately introduces a documented format revision.
- Explain any compatibility or migration implications.
