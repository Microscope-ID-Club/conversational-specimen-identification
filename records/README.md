# Specimen records

Create one folder for each specimen or explicitly defined specimen group.

Example:

```text
records/
└── BETH-2026-001/
    ├── record.md
    └── images/
```

Copy `templates/specimen-record.md` to create `record.md`. Use a stable identifier and do not rename a record after observations have been associated with it without documenting the change.

For real work, keep records in a project repository with appropriate access and data-governance arrangements. This public repository should contain only fictional or suitably generalised examples.

Do not overwrite another observer's record or resolve a conflict by discarding either version. Ask for help if two versions need reconciliation.
